# 数据文件

将 `Patio_Lawn_and_Garden_5.json` 放在本目录。文件为逐行 JSON（不是一个 JSON 数组）。

本项目使用用户已提供的 Amazon Reviews 2014 Patio, Lawn and Garden 5-core 文件。
该文件实测包含 13,272 条记录、1,686 位用户、962 件商品，勿与 2018 或 2023 版本混用。

原始来源与字段说明：<https://cseweb.ucsd.edu/~jmcauley/datasets/amazon/links.html>

数据不包含在提交压缩包中。程序不会修改原始文件；生成的拆分数据位于结果目录的 `splits`。
